# HR Analytics – Employee Attrition Analysis

## 📌 Project Overview

This project analyzes employee data to understand **employee attrition patterns, key factors associated with turnover, and HR-related insights**.

The project uses **Python for data cleaning, MySQL for data analysis, and Power BI for interactive dashboard development**.

## 🎯 Objectives

- Analyze overall employee attrition.
- Identify departments and job roles with higher employee exits.
- Analyze attrition based on salary, tenure, overtime, satisfaction, and other factors.
- Identify employee groups with higher historical attrition.
- Provide actionable insights to support employee retention.

## 🛠️ Tools & Technologies

- Python
- Pandas
- MySQL
- SQL
- Power BI
- DAX
- Excel / CSV
